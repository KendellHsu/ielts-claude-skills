# 雅思写作评分标准参考（Band 4–9）

本文件是批改时的判分依据。**Phase 2 打分前必须先读这份文件**，逐维度对照描述符定档，不要凭印象给分。

本文件依据 IELTS 官方公开评分标准（Public Band Descriptors, Writing Task 1 / Task 2）的四维框架与判准要点整理重述，非官方原文。官方原文见 <https://www.ielts.org/for-test-takers/how-ielts-is-scored>。

---

## 评分程序

1. **四个维度独立评分**：TR/TA、CC、LR、GRA，各占 25%，互不影响。不要因为一个维度差就把其他维度一起压低。

2. **定档方法**：对每个维度，找出**大部分描述符相符**的那一档，不是挑最亮眼的一条。一篇作文只要有一句好句子不代表 GRA 到 7。

3. **跨档处理**：某维度同时符合两档的部分描述符时，**取较低档**，除非高档描述符明显占多数。

4. **总分**：四维平均后按雅思规则取整——小数 .25 进到 .5，.75 进到下一个整数。例：6+5.5+5.5+6 = 5.75 → **6.0**。

5. **Task 1 用 Task Achievement，Task 2 用 Task Response**，两张表判准不同，不可混用。

6. **整体写作分**：Task 1 占 1/3，Task 2 占 2/3。只批改单篇时不要声称这是「写作总分」。

## Task Response（Task 2 专用）

| Band | 判准 |
|------|------|
| 9 | 充分回应题目所有部分；立场完整展开并贯穿全文；论点相关、充分延展、有力支撑 |
| 8 | 充分回应所有部分；主要观点相关、有延展、有支撑；个别处可能过度概括或支撑细节不足 |
| 7 | 回应所有部分；全文立场清晰；主要观点有提出、延展与支撑，但有概括倾向，或支撑论据焦点不够集中 |
| 6 | 回应了所有部分，但某些部分处理得比其他部分充分；立场相关但结论可能不清晰或重复；有相关主要观点，但部分展开不足或掺杂不清晰的细节 |
| 5 | 只部分回应题目；格式可能不当；表达了立场但发展不明显、可能没有明确结论；主要观点有限且展开不足；可能出现不相关细节 |
| 4 | 与题目只有最低限度关联，或答非所问；格式可能不当；立场表达不清；主要观点难以辨识，可能重复、不相关或缺乏支撑 |

**检查顺序**：题目有几个部分 → 每部分都答了吗 → 立场是否全文一致 → 每个论点有没有具体展开（不是只写一句概括）。

## Task Achievement（Task 1 专用）

| Band | 判准 |
|------|------|
| 9 | 充分满足所有要求；清楚且完整地呈现关键特征与数据 |
| 8 | 充分覆盖所有要求；清楚呈现并适度突出关键特征/要点；可能遗漏个别细节 |
| 7 | 覆盖要求；清楚呈现并突出关键特征/要点；但可能细节展开不足，或写入不必要的细节 |
| 6 | 覆盖要求；有 overview 但关键特征的描述可能不完整或不准确；细节可能不相关、不恰当或不准确 |
| 5 | 概括呈现数据但**没有清晰的 overview**；机械复述细节；可能出现无关、重复或不准确的内容 |
| 4 | 尝试处理但未覆盖所有关键特征；格式可能不当；可能有大量数据错误 |

**Task 1 特有检查**：

- **有没有 overview 段？没有则 TA 上限 5。** 这是 Task 1 最常见的失分点。
- 关键趋势（最高/最低、增减方向、交叉点）有没有点出？
- 数据引用准不准确？单位、时间范围有没有写对？
- **有没有写入个人观点或原因推测？** Task 1 只描述，不解释、不评价。

## Coherence & Cohesion（两个 Task 共用）

| Band | 判准 |
|------|------|
| 9 | 衔接自然到几乎不可察觉；分段处理得当且有效 |
| 8 | 信息与论点排列有逻辑；各类衔接手段掌握良好；分段充分恰当 |
| 7 | 信息与论点组织有逻辑，全文推进清晰；衔接手段使用恰当，但可能偶有过度或不足；每段有清晰的中心议题 |
| 6 | 信息与论点组织连贯，整体推进清晰；衔接手段有效但段落之间或段落内部可能有瑕疵或显得机械；指代与替换不总是恰当；分段可能不总是合乎逻辑 |
| 5 | 有一定组织但整体缺乏推进；衔接手段使用不足、过度或不准确；因缺乏指代与替换而显得重复；可能不分段或分段不当 |
| 4 | 信息与论点有呈现但组织不连贯，看不出推进；只用基本衔接手段且可能不准确或重复；可能不分段，或分段方式令人困惑 |

**检查顺序**：段落之间是逻辑递进还是平行堆砌 → 每段是否只讲一件事 → 连接词是自然还是机械（连续 However / Moreover / Furthermore 开头即为机械）→ 代词指代是否清晰。

## Lexical Resource（两个 Task 共用）

| Band | 判准 |
|------|------|
| 9 | 词汇运用自如精准，措辞自然老练；极罕见的失误仅属笔误 |
| 8 | 词汇范围广，能流畅灵活传达精确含义；不常见词汇运用娴熟，偶有搭配或选词不当；拼写与构词错误罕见 |
| 7 | 词汇范围足以具备一定灵活性与精确度；能使用不常见词汇并有一定文体意识；选词与搭配偶有不当；拼写/构词偶有错误 |
| 6 | 词汇范围足以完成任务；尝试使用较不常见的词汇但有时不准确；拼写与构词有错误，但不妨碍沟通 |
| 5 | 词汇范围有限但勉强够用；可能频繁重复；拼写与构词错误可能给读者造成困难 |
| 4 | 只使用基本词汇，可能重复使用或不适合该任务；构词与拼写掌握有限，错误可能让读者吃力 |

**检查顺序**：同一实词是否重复超过 3 次 → 有没有同义替换 → 搭配是否正确（make a decision ✓ / do a decision ✗）→ 拼写。

**注意**：硬塞生僻词但用错，比用对基础词**扣更多分**。"utilize" 到处用不会加分。

## Grammatical Range & Accuracy（两个 Task 共用）

| Band | 判准 |
|------|------|
| 9 | 句式运用完全灵活准确；极罕见的失误仅属笔误 |
| 8 | 句式多样；绝大多数句子无误；偶有错误或不当 |
| 7 | 使用多种复杂句式；多数句子无误；语法与标点掌握良好，偶有错误 |
| 6 | 简单句与复杂句混合使用；语法与标点有错误，但极少妨碍沟通 |
| 5 | 句式范围有限；尝试复杂句但准确度低于简单句；语法错误频繁、标点可能有误，可能给读者造成困难 |
| 4 | 只使用极少数句式；从句罕见；部分结构正确但错误频繁，标点常有误 |

**检查顺序**：是否全是简单句（全简单句 GRA 上限 5–6）→ 主谓一致 → 时态一致 → 冠词 → 标点（尤其逗号连接两个完整句 = comma splice）。

## 降分触发条件（硬性）

打完分后逐条核对，命中则相应维度封顶：

| 条件 | 后果 |
|------|------|
| Task 2 不足 250 词 / Task 1 不足 150 词 | TR/TA 扣分，字数越少扣越重 |
| 完全跑题 | TR ≤ 3 |
| 题目有多个部分而漏答其一 | TR ≤ 5 |
| Task 1 没有 overview | TA ≤ 5 |
| 立场前后矛盾或两边都同意 | TR ≤ 5 |
| 不分段或分段混乱 | CC ≤ 5 |
| 抄写题目原文 | 抄的部分不计入字数 |
| 大量套用背诵模板句 | 模板部分不计入字数，TR 与 LR 受限（通常锁 6 分以下） |
| Task 1 掺入个人观点/原因推测 | TA 扣分 |

## 校准提醒

- **AI 评分普遍偏高约 0.5 分。** 报告里要提醒用户：实际考试可能比这个分数低 0.5，接近目标分时尤其别当真。
- 分数的价值在**相对信号**——哪一维最弱、多篇之间的趋势——而不是绝对数值。
- 定档拿不准时**往低报**。高报会让用户误判准备程度。
- 建议用户用 2–3 个工具交叉验证（UpScore.ai / LexiBot / Engnovate）。
